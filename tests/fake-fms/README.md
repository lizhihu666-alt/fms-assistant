# FMS 插件本地测试（假 FMS）

不碰真实账单，在本地模拟的 FMS 页面上测试插件里「注入 FMS 页面」的脚本。

## 用法
1. 在仓库根目录运行 `node tests/fake-fms/server.js`（端口 5300）
2. 浏览器打开 http://localhost:5300/fake/index.html?page=bill
3. 点页面左上角「运行全部测试」，或在控制台执行 `await __runTests()`（可传关键字只跑一部分，如 `__runTests("重新生成")`）

## 模拟了什么
- 页面：真实的 Vue3 + Element Plus + VXE-Table，DOM 结构和真实 FMS 一致（账单总表、固定在右侧的操作列、分页、账单生成弹窗、基础数据导入弹窗）
- 行为：生成账单、重新生成、导入基础数据都是异步生效；重新生成只有在缺的 SKU 都导入后状态才会变
- 竞态：页面加载时的默认查询会晚返回并盖掉筛选结果（真实 FMS 出现过）
- 开关（`__fake.config({...})`）：`regenConfirm` 点重新生成是否弹确认框；各种延迟

## 样例文件
`samples/` 里是用 `make-sample*.js` 生成的对账表样例（虚构数据），用来目测清洗结果的版式。

## 没模拟的
账单明细页（补基础数据里读缺价明细）、下载导出、请款和发票上传、EH。真实 FMS 的未知行为（比如重新生成到底弹不弹确认框）也只能两种都模拟。
