# FMS付款助手

Chrome / Edge 浏览器扩展（Manifest V3），在侧边栏里把 FMS「品牌商账单」的付款流程串成一条线：生成账单 → 补充数据 → 重新生成 → 清洗对账 → 上传发票并请款，另有「付款进度」页跟踪各账单的处理状态。

> 内部工具，仅限公司内部使用，请勿外传。作者：Leo Hu

## 功能

**请款流程**（按账单当前状态自动分叉，步骤按顺序解锁）

1. **生成账单**：按品牌，或按 Vendor（同一品牌商公司下的多个品牌一次生成）。选择店铺、结算月份后自动在 FMS 里提交。
2. **账单状态验证**：输入一张或多张账单编号（空格、逗号、换行分隔），自动读取状态。
3. **补充数据**：账单为「待确认」（基础数据缺失）时，生成基础数据导入文件（自动到 EH 查成本），复查后一键导入 FMS。
4. **重新生成账单**：导入后自动点「重新生成」，等待状态变化。
5. **下载并清洗对账表**：下载原始账单明细并清洗，同时提供中文版和 English 两个版本。同一 Vendor 的多张账单合并成一份。Justfab EU 的数据概览按结算主体、站点、品牌展开。
6. **上传发票并请款**：请款后在费控单据里上传发票，只保存为草稿，不会点「提交」。多张账单合并成一张费控单。

**付款进度**：账单概况（逾期 / 关注 / 正常 / 待出账）、需要处理的账单列表，以及完整跟踪表入口（`dashboard.html`）。

## 安装（未打包扩展）

1. 下载本仓库（Code → Download ZIP）并解压，或拿到打包好的 `FMS付款助手_日期_时间.zip` 后解压。
2. 浏览器打开 `chrome://extensions`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的文件夹（里面直接能看到 `manifest.json`）。
4. 点工具栏的插件图标，侧边栏即打开。

更新版本：用新文件覆盖旧文件夹，在 `chrome://extensions` 里点插件卡片上的刷新按钮。版本号看侧边栏右上角。

## 使用前提

- 浏览器里已登录 FMS（`fms-jf.wangoon.cn`）；补充数据还需要已登录 EH（`admin.engagehub.tsostech.com`）。
- 插件会打开 FMS / EH 页面代为点击，运行期间请不要关闭这些标签页；写入类操作会短暂切到前台标签页。
- 插件通过页面自身的接口和界面操作，不保存账号密码。

## 目录结构

```
manifest.json        扩展清单（权限、侧边栏入口）
background.js        Service Worker：长任务（生成账单、补充数据、重新生成）在后台跑，状态存 chrome.storage.local
popup.html/js/css    侧边栏界面与流程逻辑
theme-premium.css    界面外观（叠加在 popup.css 之上）
dashboard.html/js/css  付款进度跟踪表
src/
  billGen.js         生成账单、重新生成（操作 FMS 页面）
  fmsSync.js         读取账单列表、审批链
  fmsAutomation.js   下载原始账单、请款并上传发票
  baseData.js        基础数据导入文件的生成
  baseDataSync.js    读取缺失价格行、查询 EH 成本、导入 FMS
  cleaner.js         账单清洗与对账表生成（中文 / 英文）
  progress.js        付款进度计算、Vendor 分组
libs/                第三方库：ExcelJS、SheetJS
icons/               图标
```

## 开发说明

- 纯静态扩展，没有构建步骤，改完文件在 `chrome://extensions` 刷新即可。
- 在页面里执行的自动化函数都是自包含的，只返回 `{ok, ..., log}`，不抛异常。
- 每次发给同事的版本：升级 `manifest.json` 的 `version`，再打 zip。
- 本地用假 FMS 页面做自动化测试（不在本仓库里）。真实 FMS 上尚需人工验证的点：重新生成是否弹确认框、多张账单合并请款后的费控单行数。
